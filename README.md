# Nyuhuhu!!

Parches de traducción al español para novelas visuales.

**[Visitar Nyuhuhu!!](https://paytonn131.github.io/nyuhuhu/)**

En cada ficha encontrarás capturas, instrucciones de instalación, el enlace de descarga y un formulario para reportar errores.

Proyecto independiente y sin fines de lucro. Las traducciones se elaboran con IA y pueden contener errores. Los parches requieren una copia legítima del juego. Las obras y marcas pertenecen a sus respectivos titulares.
